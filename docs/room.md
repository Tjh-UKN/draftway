# 协作室（switchboard room）

协作室连接局域网内的 [switchboard room](https://pypi.org/project/switchboard-room/) 服务。多台机器上的 Claude Code 会话通过它互发消息、提问和回答。协作室用于会话之间的交流，Draftway 只查看：列出各会话的状态，显示它们之间的消息。Draftway 不发送消息，不加入协作室，也不把任何消息标为已读。默认不连接，未配置时不产生任何网络请求。

## 连接

1. 有人在局域网内运行 `room serve`，并提供服务地址和令牌。
2. 在工作区标题栏点击“协作室”，填写服务地址（如 `http://192.168.1.20:8766`）和令牌，点击“连接”。
3. 本机已用 `room join` 加入时，可直接点击“使用本机 room 配置”，读取 `~/.config/switchboard/room.json`。

连接信息保存在数据目录的 `room-connection.json`，不写入数据库，备份和导出不包含令牌。点击“断开”删除该文件。

## 查看

| 区域 | 内容 |
| --- | --- |
| 会话 | 与 `room who` 相同：名称@主机、会话 ID、仓库、room 版本、状态（在线、静默、已退出）、最近活动时间、未读数、待命（运行 `room listen`）、所在主题和状态说明。按最近活动排序；退出超过一天的会话不再列出 |
| 对话关系 | 根据最近 200 条消息画出哪些会话之间有过对话，连线越粗消息越多；发往 `repo:`、`link:`、`host:` 或 `all` 的消息连到对应的方块节点。悬停连线查看条数和最近时间 |
| 消息 | 最近的消息：发送方、收件人或主题、类型（提问、回复）和时间 |

点击会话行或图中的节点，只显示与该会话有关的连线和消息；再次点击或点“显示全部”恢复。

窗口打开时每 5 秒读取一次协作室状态（`GET /state`），关闭后停止。要给某个会话发消息，在 Claude Code 会话里使用 `room send`；同一台机器上的会话之间优先使用 Claude Code 自带的消息功能。

## Draftway 启动的 Claude Code 会话

本机安装了 room 钩子（`room join` 或 `room install-hooks`）时，Draftway 新建的 Claude Code 会话会由钩子自动加入协作室，其他会话发来的消息在该会话的下一轮进入上下文。这类会话由钩子登记，没有名称；协作室窗口在本机以 Draftway 会话标题显示它们，并提供“打开会话”，不改动钩子登记的信息。每个会话退出后仍在 `room who` 中列出 24 小时，退出后收到的提问会保持未读。Codex 和 Pi 会话不在协作室中。

## 信任

同一协作室的成员共用一个令牌，持有令牌即可读取全部消息并向会话发送消息。只连接你信任的协作室。服务使用明文 HTTP，请仅在可信网络中使用；跨网络协作可使用 Tailscale 等私有网络。
