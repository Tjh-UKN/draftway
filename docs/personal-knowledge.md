# 个人知识库

左侧「个人知识库」是工作区之外的全局入口，所有工作区共用。默认显示有层级的知识图：来源工作区是分支，笔记、网页、画板和思维导图作为内容节点，支持收起、展开、拖动整理、搜索和缩放。切换知识库会保留原工作区的页签、地图位置和会话。

「新建」或节点旁的加号可以创建分支、Markdown、HTML、Excalidraw 或思维导图。内容可以放在分支下，也可以继续包含下级内容。点击节点后查看内容或打开编辑器；详情中的「所在分支」也能调整层级，不能移到自己的下级。

- Markdown：原文编辑、预览、导出和本地保存。
- HTML：导入 `.html` / `.htm`，保留原文；预览支持内嵌脚本和样式。源码可编辑、导出。
- Excalidraw：现有画板直接显示，复用原编辑器，支持导入 `.excalidraw` / Excalidraw JSON、继续绘图和原有导出。
- 思维导图：独立保存节点层级和正文，复用工作区的标题直改、加节点、删除、撤销、复制粘贴和拖动操作。导入/导出使用 Draftway `.mindmap` 或节点 JSON（数组，或含 `nodes` 数组的对象），不解析 XMind、FreeMind 等格式。

已有笔记和画板直接进入知识图，不再复制一份；旧数据没有分支字段时自动归入来源工作区，普通个人内容归于根节点。移动后保留你指定的位置。旧备份中的缺失或异常上级不会让内容消失，会重新挂到根节点。

工作区保存后，已保留到地图的 AI 产物、有正文的文档节点，以及随记和笔记视图中的正文继续自动入库。普通节点、未保留聊天回复和空文档不入库；不自动复制整个工作区地图，不扫描外部文件夹，不执行 AI 提炼，也不改变发给执行器的原始消息。HTML 文件形式的产物按 HTML 打开。

同一来源只生成一个条目。未编辑的自动条目随来源更新；在知识库修改内容后保留整理结果，不再覆盖。仅移动层级不会停止来源同步。归档或删除后不会自动重新创建；移除来源工作区不会删除已收集知识。

Windows 继续使用原 SQLite 数据库及完整备份，格式和层级一起保存；浏览器预览使用自己的 IndexedDB，与 Windows 数据独立。文档上限 1 MB，Excalidraw 上限 20 MB，单份思维导图上限 250 个节点。保存失败保留当前编辑内容，可重试或导出。

HTML 是隔离的独立文档，不能访问工作台数据、宿主命令或网络，也不加载同目录资源。Windows 通过独立的知识预览协议提供临时页面，使用单独的 CSP 和 sandbox；关闭预览即释放，不把用户 HTML 写入应用主页面。
