# 个人知识库

左侧「个人知识库」是工作区之外的全局入口。所有工作区共用同一份知识库，切换时保留工作区的页签、地图位置和会话。知识库复用原有笔记数据，支持搜索、新建、编辑、归档、附件和 Markdown 导出。

工作区保存后，以下已有内容自动入库：

- 已保留到地图的 AI 产物，包括明确调用保留产物工具生成的节点。
- 有正文的文档节点。
- 工作区随记和笔记视图中已有的正文。

现有个人笔记直接显示，不再复制一份。普通节点、未保留的聊天回复和空文档不入库；此阶段不扫描外部笔记库或文件夹，不执行 AI 提炼，也不改变发送给执行器的原始消息。

自动入库的条目保留工作区和内容类型作为来源，同一来源只生成一个条目。尚未编辑的自动条目随源文档更新；在知识库手动编辑后，保留你的整理结果，不再由工作区覆盖。归档或删除后不会自动重新创建，来源工作区或节点移除也不会删除已经收集的知识。

Windows 使用原有 SQLite 笔记表与备份，收集和来源去重在同一事务内完成。浏览器预览使用自己的 IndexedDB，与 Windows 数据独立。单篇笔记上限为 1 MB；入库失败会在知识库显示原因和重试入口，工作区原文仍保留。
