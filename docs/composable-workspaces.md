# 组合自己的工作区

左侧「个人知识库」独立于工作区，自动收集已保留的产物、文档节点与工作区笔记，复用原有笔记管理。范围与保存方式见 [个人知识库](personal-knowledge.md)。

分区右上角「＋」打开思维导图、浏览器、文件审查、Agent 会话，或进入「业务组件」选择原有功能。目标与项目、事项备忘、工作记录与复盘、知识笔记、习惯、健康、日历、画板、文件柜、归档和数据设置继续使用原有业务逻辑与本地数据。

「思维导图」直接在当前分区打开新页签，复用工作区的地图组件。多个导图视图共享当前工作区的节点、任务、材料和会话关联，各自保留缩放、位置、折叠分支及选中的节点；可以拖动分屏，也可以关闭额外页签，节点数据仍保留。初始「工作区」页签继续作为固定入口。布局模板保留导图视图的位置，创建新工作区时清空选中节点和画布位置。

点击地图上的标题直接改名，Enter 保存，Esc 取消，点到别处也会保存；空标题保留原名称。改名只修改标题，正文、材料、会话和任务状态均保留。新节点直接输入标题。点击节点的图标、空白处或「ⓘ」打开节点信息，查看和编辑正文、材料、会话与任务。标题编辑不会打开或关闭信息面板。键盘聚焦标题后可用 F2 或空格进入编辑。

节点不再要求选择想法、分析、文档、代码或产物类型。直接在节点信息中添加子任务，勾选子任务完成状态，父任务进度自动汇总；界面不提供任务跟踪开关或手动进度条，地图节点也不显示进度条、百分比或尾部完成对勾。子任务就是地图中的节点，两处修改同步。已有进度和计划日期保留，会话执行状态和业务任务验收分别保存。

旧数据读取时会把行动步骤迁为子任务节点、把独立完成勾选迁为任务进度、把旧引用并入材料关联。已打开的材料页签会跟随新关联标识。无法识别的旧引用保留在节点内容里，重复材料的不同名称及旧状态冲突留在更新记录。首次迁移前，浏览器和 Windows SQLite 都会保留原始工作区快照；迁移不修改传入的数据，也不删除备份。若迁移后超过 250 个节点，停止自动覆盖并保留原始数据。

「工作区事件」展示当前地图的事件节点和进度，点击回到同一个节点编辑。「事项备忘」展示原版任务库，可按项目筛选。它们都可以和地图、会话或网页并排打开。用户编辑业务记录后，其他已打开的业务组件会刷新。

业务组件在分区内编辑，不增加第二套全局侧栏。普通记录表单草稿在本次打开期间随工作区恢复；关闭编辑器会丢弃该草稿。大型草稿可能超过临时浏览器存储容量，画板继续使用其原有保存方式。

## 布局模板

在「自定工作区」的「布局模板」保存当前组合。之后新建工作区可以选择该模板。模板只包含分屏、组件入口和网页地址，不复制会话、文件差异内容、地图内容或目录授权。新网页实例生成独立标识，不会和原工作区抢同一个原生浏览器视图。

相同名称再次保存会更新模板；列表内可以移除不再使用的模板。模板最多 30 个，工作区仍按现有容量限制管理。

## 接入声明

在「自定工作区」导入 `northstar.integration/1` JSON。示例见 [PR 看板声明](../examples/integrations/pr-review.json)。导入后从「＋ → 业务组件 → 接入工具」打开。Windows 版使用隔离的 WebView2；远程页面没有北极星命令权限。

第一版声明式接入只启用网页入口。声明中的未知能力会保留，不能因此取得运行命令、文件读取或启动/取消检视的权限。本机检视状态观察、Obsidian 材料和 Agent 会话使用已实现并验证过的宿主适配器，分别在相应界面配置。

## 验证

已通过模板清理与独立实例、声明校验、可信业务页桥接的单元检查；Windows 运行探针验证业务页识别桌面宿主、命令回到主 WebView、原生事件和监听清理。浏览器实际操作验证事项页面、编辑弹窗以及切换工作区后恢复未保存草稿。新增导图视图的分屏打开、节点创建与编辑同步、刷新恢复及节点新建会话也已通过浏览器操作验证；会话创建检查使用浏览器模拟模式。

业务页共享 Windows SQLite；浏览器预览使用该浏览器的独立 IndexedDB。此实现没有覆盖已安装原版的数据目录。
