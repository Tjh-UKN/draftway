## 阶段与验收

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| 1. 工作区骨架与网页 | 递归分屏、混合页签、节点和事件进度、材料链接、Windows WebView2 | 布局与草稿恢复、关闭保留会话、真实 PR 看板加载、网页无宿主命令权限 |
| 2. 真实 Agent 会话 | 适配器发现、工作目录、创建/续聊/停止、流式消息、执行记录与恢复 | 至少一个已配置后端完成真实多轮会话；其他后端按实际安装/认证状态启用，不伪装成功 |

## 保持的交互

- 每个分区只有一个“＋”入口；选后端后直接进入会话，节点详情保留醒目的创建按钮。
- 点节点旁“＋”直接建节点，不要求标签、位置或初始正文。
- 节点、会话、执行、产物分别保存。关闭页签不停止执行；停止需要明确操作。
- 真实会话可关联多个节点，材料与执行结果可回到节点；不把每段会话都放到地图。
- 工作区可新增和自定义，组件以能力注册；未实现、未安装或未认证的能力明确不可用。

## 提交约定

每个阶段提交实现、相关测试及此处的交付记录，推送后核对远端提交。构建产物、个人配置、凭据和运行数据不提交。此分支的阶段提交不自动合并 `main` 或覆盖已安装原版。
