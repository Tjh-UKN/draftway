# 思维导图编辑

在工作区或新建的思维导图页签中，点击标题直接改名；点击图标、空白边缘或信息按钮打开节点详情。标题编辑不需要打开详情。

| 操作 | 使用方式 |
| --- | --- |
| 删除节点及整支子节点 | 右键 → 删除节点及子节点，或聚焦节点后按 Delete / Backspace；详情栏右上角也有删除入口 |
| 撤销 / 重做 | Ctrl Z / Ctrl Y（或 Ctrl Shift Z）；画布下方也有按钮 |
| 添加子节点 | 节点加号、Tab 或 Insert |
| 添加同级节点 | Enter；中心节点没有同级，此时添加子节点 |
| 修改标题 | 点击标题、F2 或空格；Enter 保存、Esc 取消；编辑标题时 Tab 保存并添加子节点 |
| 节点间移动焦点 | 左：父节点；右：首个子节点；上下：同级节点；Shift Tab：父节点 |
| 多选 | Ctrl 点击节点；Ctrl A 选择当前地图可见节点；Shift 拖动画布框选；Esc 取消多选 |
| 复制 / 剪切 / 粘贴 | Ctrl C / X / V，或右键菜单；粘贴到当前节点下面 |
| 调整层级和顺序 | 拖到目标节点中间成为子节点；拖到上沿 / 下沿成为同级节点 |
| 收起 / 展开 | 节点分支按钮或右键菜单 |

删除和移动始终保留工作区中心节点。多选包含父子节点时，只处理一次分支；删除、剪切和移动都可整批撤销。不允许拖入自己的子节点。

删除地图节点会解除它的会话关联并关闭对应材料页签；会话、执行记录、原始材料和已经入库的个人知识保留。撤销恢复节点和仍未被其他操作改变的关联。后台会话同步不会把已删除的关联写回来。

本窗口内跨工作区复制会保留分支层级、正文和材料；不会复制会话身份或执行历史。系统剪贴板带入外部应用的是缩进标题，外部缩进文本也可以粘贴为节点。若浏览器限制系统剪贴板，菜单会明确提示并使用本窗口最后复制的分支；外部内容可用 Ctrl V 粘贴。

撤销历史按工作区隔离，保留当前窗口最近 30 步，重启后不保留。后续 AI 修改过同一字段时，撤销会提示冲突并保留当前内容。每个工作区最多 250 个节点，超限粘贴整批取消。

参考知犀的[快捷操作](https://help.zhixi.com/guide/172.html)与[跨文件复制](https://help.zhixi.com/advanced/8703.html)交互；当前实现覆盖以上基础编辑，不包含知犀的所有高级样式、导出和模板功能。
