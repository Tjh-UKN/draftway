# 后台执行与提醒

Windows 版切换工作区、关闭会话页签或收起到托盘后继续执行。退出北极星会停止由它启动的执行器；下次启动保留历史并把未完成执行标为中断，不伪装成功。浏览器预览不能托管本机执行器。

通知中心集中显示执行完成、失败、需要输入和 PR 检视结果。点击会话结果打开原会话；点击检视结果打开对应文件的只读报告，可再打开原看板。后台完成不会切换当前工作区。前台已有焦点、已读或关闭系统提醒时不弹系统提示。

在「自定工作区」启用「跟踪本机 PR 检视」，填入本机服务地址，例如 `http://127.0.0.1:8765/`。此适配器只 GET 状态和报告，不启动检视、不发布意见。已有该地址的原检视工作区自动建立绑定；取消后不会再次自动启用。

首次连接记录历史基线。报告只有 `completed`/`noop` 且失败数为零才算成功；`failed` 为失败，阶段文件和 `in_progress` 保持进行中。调度暂停、停止或网络断开不代表任务完成。来源列表最多保留 50 条；离线时间过长、无法和历史重叠时提示可能遗漏。

任务快照与待发送提醒在同一 SQLite 元数据事务中保存。重复快照不重复建立通知，相同来源结果绑定多个工作区时保留各工作区入口、只投递一次系统提示。投递失败每 30 秒重试；系统接受提示不证明用户已看到，投递后立即崩溃仍可能在恢复时重复投递。

Windows 系统提示需要应用身份和系统通知设置支持。未安装的独立预览可能不显示系统横幅，通知中心仍可查看。当前已验证解析、去重、恢复、只读实际接口及 Windows 构建；尚未通过 GUI 捕获验证系统横幅和点击交互。
