# 材料与文件审查

在节点「关联材料」粘贴文件路径、Obsidian 笔记链接或网页。点击网页在工作区浏览器打开；点击文本材料在独立页签只读阅读。重新读取会获取磁盘上的当前内容，用原应用打开可定位 Obsidian 笔记或关联文件。

Windows 版在「自定工作区」选择工作目录，或添加材料目录。Obsidian 库对应的材料目录名称须与链接里的 `vault` 名称相同。宿主按文件的真实路径检查目录范围，路径穿越及越过目录的链接不会扩大读取范围。解除目录后，关联仍保留，读取会重新校验。

内置阅读支持 1 MB 内的 UTF-8 文本；其他格式使用原应用。程序、脚本等格式不从材料按钮执行。浏览器预览不能读取任意本机路径。

节点里创建的真实会话，在每次发送时附带当时的节点标题、内容、进度和最多 20 份关联材料。每份文本取前 12000 字符，整体引用内容取前 30000 字符；网页只提供链接，不暗中抓取。超出目录或无法读取的材料会列出原因。本轮上下文快照保存在执行记录，可展开查看；不会因后续编辑笔记而改变历史来源。

文件审查页的「Git 改动」读取工作目录的未提交文件，以 HEAD 与工作目录比较，包含暂存和未暂存改动。未跟踪文件的旧版本为空，删除文件的新版本为空；重命名按删除和新增展示。支持每个版本 256 KB、5000 行内的文本，不执行提交、还原或写入文件。

已验证目录与 Obsidian 解析、越界拒绝、真实临时 Git 仓库的修改/新增/删除/子目录范围，以及 Codex 实际收到引用材料和重启后的上下文记录恢复。Obsidian 原应用唤起和 Windows 鼠标交互尚未通过 GUI 回归。
