# 北极星第一阶段：地图与会话骨架

状态：已实现本地前端骨架，入口 `/next.html`。Windows 原生网页容器已接入独立预览版；真实 Agent、原业务数据库迁移和系统后台执行宿主尚未接入。

## 工作区交互

- 左侧保留全局导航和工作区列表；工作区单击切换，`Alt + 1…9` 直达。
- 地图是工作区主体。每个分区保留自己的页签栏与“＋”，顶部只保留会话记录、通知和工作区设置。点地图节点旁的“＋”直接生成子节点并选中名称，不弹表单，不要求先选类型、位置或填写正文。类型与内容在创建后按需编辑。没有全局 Agent 会话入口；新会话直接成为“工作区”旁边的页签。
- 节点支持想法、分析、任务、文档、代码与产物。点击后在右侧查看内容、关联会话、更新记录和引用；任务继续支持进度和行动步骤。
- 分区页签栏“＋”可打开浏览器、文件审查或选择 Agent 后端创建普通会话；节点详情“关联会话＋”选择后端后直接创建并打开，自动关联当前节点。两种入口均不填写表单、不另点确认、不生成地图节点。会话记录只管理已有会话。
- “工作区”地图页签保留且可移动；地图、会话、浏览器和文件审查可以在同组切换，也可以同时放在不同分区。地图位置和节点选择保留。页签显示后端、标题、运行／等待输入／失败状态与未读标记，支持拖动排序、关闭、方向键切换和 Ctrl + Tab 最近使用切换。
- “会话记录（N）”用于查找、重新打开已有会话，不放置创建入口。再次打开已在页签中的会话只聚焦，不重复打开。
- 会话独立于页签。关闭页签保留消息、草稿和执行记录；每个工作区独立保存页签顺序、最近使用顺序、当前选择和记录面板状态。新会话默认命名，首次发送消息后取首行作为标题；标题不改变会话标识和后端归属。

## 分屏与工具页签

参考 [Orca 的分区机制](https://orca.dev/docs/model/tabs-panes-splits)，一个页签只归属一个分区，分区构成递归树：

- 分区“＋”中直接选择浏览器、文件审查或 Agent；选后端即进入会话，不增加创建表单。
- 向右／向下分屏可继续嵌套，当前预览最多 8 个分区。只有一个页签时分出空分区；有多个时把当前页签移到新分区。
- 拖动页签可组内排序、跨组移动；拖到内容区四边可直接分屏。拖动分隔线调整大小，也可聚焦分隔线后用方向键调整；合并所有分区保留全部页签。
- 关闭最后一个可关闭页签时自动收拢该分区；地图页签保留。关闭会话页签保留消息、草稿和执行状态，可从会话记录或节点重新打开。
- 每个工作区保存自己的分区树、分隔比例、页签、当前分区和最近使用顺序。Ctrl + Tab 切换当前工作区最近页签；Ctrl + Shift + [ / ] 切换当前分区页签。
- Windows 独立预览版使用 WebView2 子视图直接加载网页，自动 PR 看板无需修改安全响应头。地址栏同步实际导航和标题；前进／后退操作页面的真实历史。移动页签、切换工作区只调整位置或隐藏，保留原生页面与历史；关闭页签才释放视图。新窗口链接可转为当前分区的新页签。
- 浏览器中的 `/next.html` 继续使用 iframe，仍受站点嵌入限制；这与 Windows 原生承载分别实现。浏览器预览只管理地址栏提交的历史。两种模式重新启动后恢复最后保存的 URL，不承诺恢复整段历史。
- 文件审查通过系统选择器读取本地文本快照，单文件最多 256 KB／5000 行；可选择第二份文件查看真实增删行。差异计算使用 jsdiff 并设时间上限；仅做只读本地审查，尚未连接 Git 工作区、PR 服务和逐行评论。快照随页签保存在本机，原文件不被修改。

## Windows 原生预览与验证

`npm run desktop:next:build` 构建独立的 Windows 预览程序；开发时先启动 `npm run dev`，再运行 `npm run desktop:next`。预览配置使用 `com.northstar.workbench.preview`，存储与已安装原版、浏览器预览分别管理；不会自动迁移浏览器中的工作区。当前交付副本位于 `artifacts/native-preview/northstar.exe`，无需安装程序。

原生实现使用仓库锁定的 Tauri 2.12.1 `unstable` 多 WebView API。坐标按宿主实际像素尺寸换算，跟随分隔线、窗口大小和 DPI；菜单、对话框、通知、拖动时暂时隐藏原生视图，关闭后恢复。网页聚焦时的全局工作区快捷键尚未统一拦截。

宿主权限仅授予主 WebView `main`。网页使用独立浏览器配置目录，不能执行北极星自定义命令；导航限定 HTTP／HTTPS，并拒绝宿主和 IPC 地址。不放宽看板的 `X-Frame-Options` 或 CSP。

`npm run test:native-browser` 启动临时的禁止 iframe 嵌入页面，用原生 API 验证创建、真实历史与后退、隐藏恢复、尺寸换算、访客命令拒绝和关闭释放。设置 `NORTHSTAR_BROWSER_DASHBOARD=http://127.0.0.1:8765/` 可额外加载正在运行的真实 PR 看板。运行结果保存在 `artifacts/native-browser-runtime.json`；本轮 7 项检查通过，真实看板标题为 `PR Review Control`，原响应头仍为 DENY／frame-ancestors none。

Windows GUI 截图工具连续返回 capture timeout，鼠标点测、菜单遮挡和拖放回归尚未完成；上面的原生运行检查不代替 GUI 验证。浏览器分屏骨架已在上一阶段点测，真实 Agent 仍为模拟执行。

## 节点关联材料

节点详情增加“关联材料＋”，粘贴一行链接或完整文件路径后按 Enter 添加，名称自动识别。支持多份材料、去重、本地保存和解除关联；不增加节点创建步骤。旧 `reference` 字段保留并显示在同一列表中。

- Obsidian：使用笔记的 `obsidian://open` 链接，也支持 vault 路径简写；保留库、笔记路径和标题／块定位，点击交由系统打开 Obsidian。仅允许打开已有资源，不接收新建、覆盖笔记或回调动作。
- 网页：支持不含登录凭据的 HTTP／HTTPS 链接，在独立页面打开。
- 文件：支持 Windows 路径及 file URL，显示文件名并提供复制路径；浏览器预览不声称能直接打开任意本机文件。

材料列表与节点一起保存，不复制、修改或删除原材料。当前没有读取或同步 Obsidian 笔记正文。Obsidian URI 格式与复制入口依据 [官方说明](https://help.obsidian.md/Extending+Obsidian/Obsidian+URI)。已验证关联、刷新恢复、解除关联和生成链接；本机 Obsidian 的实际唤起未验证。

## 地图更新约定

会话输入区只保留输入、发送和停止，不展示地图动作、模拟结果选择或节点关联下拉框。节点关联在节点详情中按需操作。以下动作属于适配器与宿主的内部契约，用于验证未来 Agent 返回结果后的行为，不要求用户在聊天前选择：

| 动作 | 宿主行为 |
| --- | --- |
| 仅回复 | 保存会话结果，不增加地图节点 |
| 生成产物节点 | 执行成功后创建产物节点，关联来源会话并写入更新记录 |
| 追加节点进展 | 向明确选中的上下文节点追加一条带来源的记录 |
| 更新节点内容 | 更新明确选中的节点正文，并记录来源会话 |

普通回复的产物也可以由用户点击“保留到地图”主动放置。重复点击或重复处理同一执行结果不重复生成节点和进展；失败、停止、等待输入不触发地图写入。修改目标必须属于执行会话的工作区，不能跨工作区更新。

生成产物节点和创建会话是两种不同操作。只有明确选择生成产物的执行结果，或用户主动保留的结果，才放到地图。模拟运行不自动把任务进度设为完成。

## 数据与恢复

工作台沿用独立的 `northstar-shell-v2` 本地存储，可读取本轮之前的浮动窗口状态，将当前打开的会话恢复为页签，并将旧单组页签迁移到初始分区；其他会话保留在记录中。兼容读取更早的 `northstar-shell-v1` 和 `northstar-design-v2`，旧键保持原样。消息、草稿、节点标识和业务内容保留。

读取不兼容或损坏数据时停止自动覆盖并显示错误；本地存储空间不足时明确提示尚未保存。原版 SQLite／IndexedDB 业务数据库没有被迁移或改写。

## 验证与限制

单元检查覆盖迁移、新建会话不生成节点／标签、工作区会话隔离、页签顺序、焦点恢复、会话草稿、结果通知、三类地图更新、来源记录、重复处理去重，以及失败和跨工作区写入边界。

桌面交互使用独立本地预览端口验证，避免写入用户当前预览。原有地图更新与新建会话不生成节点的边界保持；本轮已通过 59 项单元检查和前端构建；桌面预览实际验证了选择后端直接新建页签、方向键和 Ctrl + Tab 切换、独立草稿和刷新恢复、返回地图位置不变、后台完成显示未读，以及关闭后从记录恢复且不重复打开。

所有 Agent 执行和地图更新均为明确标注的模拟行为：不会调用模型、读取或修改项目文件，不代表真实 Codex／Claude Code／Pi 已接通。执行轮询依赖页面打开，关闭页面后没有系统后台托管；再次打开按保存的模拟截止时间补齐结果。
